# neo-design-patterns-hw-02

## Опис

У цьому проєкті було проведено рефакторинг системи повідомлень відповідно до принципів SOLID.

### Реалізовано:

- SRP — кожен клас має одну відповідальність;
- OCP — нові канали повідомлень можна додавати без зміни існуючого коду;
- LSP — усі канали повідомлень реалізують спільний інтерфейс;
- ISP — інтерфейси розділені за відповідальністю;
- DIP — залежності передаються через абстракції.

### Канали повідомлень:

- EmailNotification
- SMSNotification
- PushNotification

## Запуск проєкту

```bash
npx ts-node src/main.ts
```
